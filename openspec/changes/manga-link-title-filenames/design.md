# 設計

WCF 使用 Bridge manifest 的作品名稱與章節連結標題；閱讀器標題僅在連結無名稱時作為 fallback。輸出層先清理網站尾綴及不安全字元，再用固定版本 opencc-js 的 cn → tw 字典離線轉換。只轉漫畫輸出標題，不修改小說或圖片內容。

檔名將書名與卷／話名稱分別限制長度後組合，避免長書名截掉卷別；EPUB／KEPUB 使用相同 stem。發布時保護已列入 outputGroups 的輸出，避免同一工作有重複連結名稱時覆蓋其他章節；既有未完成發布的恢復邏輯保留。

標題是不可信文字，仍須經檔名清理及 XML escape；不從網址推測卷／話、不執行網頁提供的程式。Bridge protocol、憑證分離、圖片完整性、lazy-load、分頁、安全限制與重試識別不變。轉換字典初始化一次；字串及檔名仍有界。

不採用逐字手寫對照表或以清單序號推測話數，避免字詞誤轉及混合卷／話目錄錯誤。
