# 漫畫輸出沿用連結名稱

使用者要求漫畫檔名採簡化後的書籍連結名稱並轉繁體，避免將目錄中的第一卷誤認為第 22／23 話。

範圍：WCF 新產生的漫畫 EPUB／KEPUB 以清理後的書名及目錄連結標題命名，使用離線臺灣繁體字形轉換；顯示標題與 EPUB metadata 一致。相同名稱保留既有檔案並加入數字尾碼。

非目標：不更動 Bridge、Extension、網站規則、小說內容、工作順序或正在執行的服務。不重新命名已發布檔案，不重啟或重試既有工作，不部署。

隱私：轉換完全在本機進行，不送出書名、網址或認證。

相容性：新漫畫檔名改用來源名稱；原有下載連結及 checkpoint 恢復保留。缺少有效標題時保留明確的章節序號 fallback，不能推算話數或卷數。

回復：撤回本次程式與套件變更即可；已發布輸出保持原名。

停止條件：需要變更認證、網站存取限制或操作既有工作時停止該部分；未驗證項目保持待辦。
