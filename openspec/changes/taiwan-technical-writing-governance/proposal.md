# 提案：臺灣中文技術寫作治理

## 背景與目的

在本 repo 的 AGENTS.md 加入一致的中文寫作常駐規則，並新增可於適用任務自動啟用的 write-taiwan-technical-chinese 技能，讓技術規格、操作文件、驗收與審查內容維持清楚、精確且符合臺灣用語。

## 範圍

- 僅新增根目錄 AGENTS.md 的共通寫作規則與技能指引。
- 新增 .agents/skills/write-taiwan-technical-chinese/SKILL.md 與 agents/openai.yaml。
- 保留既有治理規則、程式識別字、命令、結構化欄位、原始資料值、正式名稱及必須逐字引用的來源。
- 新寫或實質改寫的中文使用臺灣繁體中文與臺灣慣用詞；必要時自動啟用技能。

## 非目標

- 不改產品程式、API、Bridge protocol、執行期、相依套件或部署設定。
- 不批次翻譯現有文件，也不改變既有文件的語言範圍。
- 不納入私人資訊、憑證、個人 URL 或非公開資料。

## 隱私、安全與相容性影響

本變更只加入通用寫作指引與技能中繼資料，不收集或輸出使用者資料。公開 repo 內容維持 generic。程式行為、公開契約、Bridge 權限、資料格式與相依性均不變。

## 回復與停止條件

回復時只移除本提案、技能檔案與新增的 AGENTS.md 區段。若 base SHA 改變、目標技能已存在、transfer 檔案校驗不符、文件會要求翻譯既有其他語言內容，或發現隱私／契約影響超出上述範圍，停止套用並重新評估。
