# 技術寫作治理規格

## ADDED Requirements

### Requirement: 臺灣繁體中文技術文件

新撰或實質改寫的中文技術文件 MUST 使用臺灣繁體中文與臺灣慣用詞，且 MUST NOT 使用簡體中文或中國用語。程式識別字、命令、路徑、結構化資料欄位、原始資料值、正式名稱與必須逐字引用的來源 MUST 保留原樣；不得為了文風修改其內容。

#### Scenario: 編寫新的中文技術文件

- **GIVEN** 作者新增或實質改寫中文技術文件
- **WHEN** 文件完成
- **THEN** 自行撰寫的中文使用臺灣繁體中文與臺灣慣用詞，不含簡體中文或中國用語
- **AND** 條件、否定、例外、數量、單位、範圍、順序及不確定性維持原意

#### Scenario: 保留既有語言與機器內容

- **GIVEN** 既有文件使用英文，或內容包含程式識別字、命令、資料欄位、原始資料值或需逐字保留的來源
- **WHEN** 作者依本規格編輯相關技術內容
- **THEN** 作者只調整本次授權的說明文字，不批次翻譯其他文件或改寫上述內容

### Requirement: 適用時自動啟用技能

撰寫或修訂技術規格、README、操作程序、驗收與審查報告，或需改善清晰度與術語一致性的實質改寫時，寫作技能 MUST 可依任務自動啟用。一般閒聊與簡短回覆不要求啟用。

#### Scenario: 撰寫適用的技術文件

- **GIVEN** 任務需要撰寫或實質改寫技術文件
- **WHEN** 作者開始工作
- **THEN** write-taiwan-technical-chinese 技能可自動啟用，並依任務內容保留原意與必要證據

#### Scenario: 處理公開 repo 文件

- **GIVEN** 目標文件位於公開 repo
- **WHEN** 作者套用寫作規則
- **THEN** 文件只包含可公開的通用內容，不含秘密、憑證或私人識別資訊
